# LaTeX Outputs

The canonical manuscript is [`../preprint.md`](../preprint.md). The supported renderer and current official NeurIPS output live under `neurips_2026/`; see [`../README.md`](../README.md) for verification and build commands.

`main.tex`, `main.bbl`, `references.bib`, and `main.pdf` are a frozen, venue-neutral conversion created before the generated pipeline. They remain available for comparison, but they are not source files and must not be edited. New prose, tables, citations, and figure references belong in `preprint.md`.
